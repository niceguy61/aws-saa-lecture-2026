# AWS OT (2026-03 to 2026-04)

비 인프라 인력도 포함해, AWS를 "업무 언어"로 이해하고 팀 간 커뮤니케이션 비용을 줄이기 위한 OT 과정이다.

## Audience

- 개발자: 제품 기능을 더 빨리, 더 안전하게, 더 싸게 출시하기 위한 선택지 이해
- 기획자 및 PM: 리드타임, 리스크, 비용 구조, 의사결정 기준 확보
- 온프레미스 운영자: 네트워크, 보안, 운영, 장애 대응 관점에서 클라우드 운영 모델 이해

## Outcomes (Must)

- "이 요구사항이면 이 서비스" 수준의 기본 매핑을 할 수 있다.
- 보안과 비용의 기본 함정(권한, NAT, 데이터 전송, 키 공유)을 피할 수 있다.
- AWS 용어로 아키텍처를 설명하고, 팀 간 합의에 필요한 질문을 던질 수 있다.

## Format (Default)

- 주 1회, 총 8회(2026년 3월~4월)
- 세션당 2h theory + 2h demo or workshop (console-first)
- 매 세션: 핵심 다이어그램 2개 이상 + 미니 퀴즈 8~12문항
