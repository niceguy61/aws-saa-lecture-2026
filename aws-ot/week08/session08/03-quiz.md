# Quiz - Session 08 (Review)

## Q1

**Scenario:** "누가 무엇을 했나" 감사가 필요하다. 도구는?

A. CloudTrail  
B. Config  
C. CloudFront  
D. EBS snapshot  

**Answer:** A  
**Explanation:** API 활동은 CloudTrail이다.  

## Q2

**Scenario:** "15분 이상 실행" 요구가 있다. Lambda 단독은 왜 위험한가?

A. Lambda는 DNS 서비스다  
B. Lambda는 실행 시간이 최대 15 minutes다  
C. Lambda는 스토리지 서비스다  
D. Lambda는 KMS를 지원하지 않는다  

**Answer:** B  
**Explanation:** 제한 때문에 오케스트레이션과 다른 컴퓨트를 조합해야 한다.
