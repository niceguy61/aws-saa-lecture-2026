# Quiz - Session 05

## Q1

**Scenario:** 복잡한 조인과 트랜잭션이 필요하다. 후보는?

A. DynamoDB  
B. RDS 또는 Aurora  
C. S3 lifecycle  
D. CloudFront  

**Answer:** B  
**Explanation:** 관계형 요구는 RDS 계열이 자연스럽다.  

## Q2

**Scenario:** DynamoDB에서 전체 탐색은 비용과 성능 함정이 될 수 있다. 무엇을 말하는가?

A. Query  
B. Scan  
C. Invalidation  
D. Failover  

**Answer:** B  
**Explanation:** Scan은 전체 탐색이라 커질수록 비싸진다.
