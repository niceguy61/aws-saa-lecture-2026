# Quiz - Session 01

## Q1

**Scenario:** Shared responsibility model에서 고객이 반드시 책임져야 하는 영역은?

A. AWS 데이터센터 물리 보안  
B. AWS 네트워크 백본 운영  
C. IAM 권한과 계정 보안 설정  
D. 하이퍼바이저 패치  

**Answer:** C  
**Explanation:** 계정과 권한, 데이터와 설정은 고객 책임 영역이다.  

## Q2

**Scenario:** AZ를 사용하는 가장 직접적인 이유는?

A. 더 많은 DNS 레코드를 만들기 위해  
B. 장애 격리를 통해 가용성을 올리기 위해  
C. 비용을 무조건 줄이기 위해  
D. 암호화를 자동으로 하기 위해  

**Answer:** B  
**Explanation:** AZ 분산은 장애 영역을 줄이는 기본 패턴이다.  

## Q3

**Scenario:** "AWS가 보안을 다 해준다"는 주장에 대한 가장 올바른 반응은?

A. 맞다. 고객은 보안을 신경 쓸 필요가 없다  
B. 틀리다. 고객은 계정과 권한, 데이터 보호를 책임진다  
C. 맞다. IAM은 불필요하다  
D. 틀리다. AWS는 물리 보안을 하지 않는다  

**Answer:** B  
**Explanation:** Shared responsibility로 책임이 분담된다.
