# Session 04 - App delivery options - Lambda and containers

## Outcomes

- Lambda, ECS Fargate, EC2의 차이를 "운영 부담과 실행 모델"로 구분한다.
- Lambda 15 minute 제한이 설계에 주는 의미를 설명한다.
- Step Functions가 "흐름 제어"를 담당한다는 것을 이해한다.

## Why This Matters (by role)

- Developer: 기능을 빠르게 배포하는 선택지가 늘어난다.
- PM or Planner: 배포 모델이 비용과 일정에 직결된다.
- On-prem Ops: 운영 방식이 "서버 관리"에서 "서비스 운영"으로 이동한다.

## Timebox (4h)

- Theory: 2h 30m
- Demo or Workshop (console-first): 1h
- Quiz and Review: 30m
