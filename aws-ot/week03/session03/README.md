# Session 03 - Identity and security 101

## Outcomes

- IAM 정책 평가(Explicit deny 우선)를 개념으로 이해한다.
- KMS와 Secrets Manager가 데이터 보호에서 어떻게 쓰이는지 설명한다.
- CloudTrail이 "누가 무엇을 했나"를 남기는 감사 도구임을 이해한다.

## Why This Matters (by role)

- Developer: 최소 권한과 시크릿 관리 없이 배포는 곧 장애로 이어진다.
- PM or Planner: 보안 요구는 일정과 비용을 바꾼다. 용어를 알아야 합의가 된다.
- On-prem Ops: 계정과 정책이 곧 네트워크와 서버의 경계가 된다.

## Timebox (4h)

- Theory: 2h 30m
- Demo or Workshop (console-first): 1h
- Quiz and Review: 30m
