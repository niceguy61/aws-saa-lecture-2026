# Quiz - Session 03

## Q1

**Scenario:** IAM 정책 평가에서 가장 우선되는 규칙은?

A. Allow가 많으면 Allow  
B. Explicit deny는 항상 deny  
C. SCP는 권한을 부여한다  
D. Group이 리소스 정책을 가진다  

**Answer:** B  
**Explanation:** Explicit deny는 최우선이다.  

## Q2

**Scenario:** 시크릿 rotation 요구가 있다. 정답 후보는?

A. S3  
B. Secrets Manager  
C. Route 53  
D. NACL  

**Answer:** B  
**Explanation:** rotation 요구는 Secrets Manager 힌트다.
