# Quiz - Session 07

## Q1

**Scenario:** 프라이빗 서브넷에서 S3 접근이 많다. NAT 비용을 줄이는 정답 후보는?

A. S3 gateway endpoint  
B. 더 큰 EC2  
C. CloudTrail 비활성화  
D. S3 퍼블릭 오픈  

**Answer:** A  
**Explanation:** S3 접근 중심이면 endpoint가 NAT 의존을 줄인다.  

## Q2

**Scenario:** 팀별 비용 분리를 위해 가장 먼저 필요한 것은?

A. 태그 표준화  
B. WAF 설정  
C. CloudFront invalidation  
D. KMS key rotation  

**Answer:** A  
**Explanation:** 차지백은 태그 또는 계정 분리가 출발점이다.
