# Quiz - Session 06

## Q1

**Scenario:** "누가 보안 그룹 규칙을 변경했는지"를 확인하려 한다. 후보는?

A. CloudTrail  
B. Config  
C. CloudFront  
D. Secrets Manager  

**Answer:** A  
**Explanation:** API 활동은 CloudTrail이다.  

## Q2

**Scenario:** "리소스 구성 상태와 준수"를 보고 싶다. 후보는?

A. CloudTrail  
B. Config  
C. Route 53  
D. WAF  

**Answer:** B  
**Explanation:** 구성과 준수는 Config다.
