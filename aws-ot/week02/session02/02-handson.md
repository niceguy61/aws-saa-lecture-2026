# Demo or Workshop (Console-First): S3 and IAM role concept

## Goal

- S3 버킷을 만들어 오브젝트를 업로드하고 기본 접근 제어 위치를 확인한다.
- IAM에서 user와 role 메뉴를 비교하고 "키 공유" 함정을 토론한다.

## Steps

### A) Console Steps

1. S3 버킷을 생성한다(학습용, 퍼블릭 차단 유지).
2. 텍스트 파일 1개를 업로드한다.
3. Permissions에서 Block public access와 Bucket policy 위치를 확인한다.
4. IAM에서 Users와 Roles 화면을 보고 차이를 토론한다.

### B) Optional

- 역할 전환(Switch role) 메뉴 위치 확인

## Cleanup

1. 업로드한 오브젝트 삭제
2. S3 버킷 삭제
