# Session 02 - AWS basics map - VPC EC2 S3 IAM

## Outcomes

- VPC, Subnet, Security group, Route table의 역할을 한 문장으로 설명한다.
- EC2와 S3를 "컴퓨트와 스토리지"로 구분하고 기본 사용 케이스를 말할 수 있다.
- IAM user와 role의 차이를 "키 공유" 관점에서 설명한다.

## Why This Matters (by role)

- Developer: 최소한의 네트워크와 권한 모델을 알아야 배포와 장애 대응이 빨라진다.
- PM or Planner: 요구사항이 인프라 비용과 리드타임에 어떻게 연결되는지 이해한다.
- On-prem Ops: 네트워크 경계와 권한 경계를 AWS 모델로 다시 표현한다.

## Timebox (4h)

- Theory: 2h
- Demo or Workshop (console-first): 1h 30m
- Quiz and Review: 30m
