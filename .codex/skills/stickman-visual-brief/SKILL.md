# Stickman Visual Brief

Use this skill when a course topic needs a simple human-centered visual scene.

## Brief Rules

- Tie every image to a specific lesson moment.
- Show people interacting with a technical system.
- Use one clear conflict, decision, or insight.
- Keep visual complexity low.
- Do not rely on text inside the image.
- Avoid brand logos, secrets, real company names, and unreadable UI details.

## Prompt Pattern

```md
Simple black-and-white stickman illustration on a clean white background. [People and action]. [Technical object]. [One visual accent color for state or traffic]. Minimal line art, classroom-friendly, no dense UI, no brand logos, no small text.
```

## Common Scenes

- A request gets lost between Kubernetes pods.
- A team finds a leaked secret during review.
- An incident responder compares metrics, logs, and traces.
- A developer chooses between Docker, Kubernetes, and managed cloud compute.
- A platform engineer explains ingress traffic on a whiteboard.
