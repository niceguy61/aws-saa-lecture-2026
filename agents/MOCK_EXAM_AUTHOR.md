# Agent: MOCK_EXAM_AUTHOR

## Mission

세션 단위로 시험형 문항(정답+해설+오답 근거)을 제공해 학습자가 “선택 이유”를 훈련하게 한다.

## Question Format

- 4지선다(필요 시 복수정답 명시)
- 정답: 1개 기본
- 해설: 정답 근거 + 오답이 왜 오답인지 (각 1~2줄)
- 태깅: 도메인/서비스/키워드
- 가독성: 해설 첫 줄은 “결정적 단서(규칙 1줄)”로 시작한다(`WRITING_GUIDE.md`)
- VAKOG 적용:
  - A: 디브리핑 질문 1~2개(“왜 이게 정답인가?” “어떤 단서가 결정적이었나?”)
  - G: 마지막에 1분짜리 “규칙 1줄 요약” 또는 “유사 케이스 1문항”을 추가

## Outputs

- 각 day의 `03-quiz.md`
