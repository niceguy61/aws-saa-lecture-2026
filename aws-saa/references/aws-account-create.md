# AWS 계정 생성 방법 (수업/실습 준비용)

UI/문구는 바뀔 수 있지만, “계정 생성 → 루트 보안 → 관리자 작업 계정” 흐름은 고정에 가깝다.

## 준비물

- 이메일(로그인 ID)
- 전화번호(SMS/콜 인증)
- 결제 수단(Free Tier라도 보통 필요)

## 가입(계정 생성) 단계

1. AWS 가입(Sign up)에서 이메일/비밀번호/계정 이름 입력
2. 이메일 인증
3. 연락처 정보 입력
4. 결제 수단 등록
5. 본인 확인(전화/SMS)
6. Support plan 선택(보통 Basic)
7. 콘솔 로그인

## 가입 직후 필수(루트 계정)

- 루트(root)에 **MFA 활성화**
- 루트로 일상 실습/운영하지 않기(루트는 비상용)
- 루트 액세스 키는 만들지 않기(있으면 제거 검토)

## 작업용 관리자 경로 만들기(권장)

- IAM Identity Center(SSO) 또는 IAM Admin 사용자/Role 중 하나로 “관리자 작업 계정/역할”을 만든다.

## 비용 폭탄 방지(실습 환경 권장)

- `AWS Budgets` 예산/알림 설정
- 안 쓰는 리소스 즉시 종료/삭제(특히 NAT Gateway, EC2, RDS, EIP 등)
