## Repo structure (읽는 흐름)

- `weekXX/dayYY/README.md`는 그 Day의 인덱스(학습 목표/읽는 순서/핵심 비교/함정)를 담는다.
- 같은 폴더의 `01-*.md`, `02-*.md`…가 “서비스별 theory” 문서다.
- 시나리오 이미지(삽화)는 `aws-saa/assets/scenario_image/`에 모아둔다.
