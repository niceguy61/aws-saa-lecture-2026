## 읽는 방법(부담 없이)

- 각 Day의 [README.md](week01/day01/README.md)는 “오늘의 이야기 + 흐름 + Reading + Quiz” 형태의 인덱스입니다.
- Reading 링크로 들어가면 서비스별 theory 문서가 있고, 문서 하단에 참고 링크(References)도 붙어 있습니다.
- 시간이 없으시면 Day 인덱스에서 **Reading → Quiz**만 따라가셔도 됩니다.
