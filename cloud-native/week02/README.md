# 2주차 - Docker와 Docker Compose

## 목표

컨테이너를 추상 개념이 아니라 애플리케이션을 같은 방식으로 실행하기 위한 도구로 이해한다.

## 일별 계획

| 일차 | 주제 | 활동 |
|---|---|---|
| [1일차](day01/README.md) | 컨테이너 개념 모델 | 간단한 컨테이너를 실행하고 상태, 로그, 내부 접근, 중지, 삭제를 안전하게 연습한다. |
| [2일차](day02/README.md) | Docker Image | 간단한 API 이미지를 빌드하고 tag를 붙인 뒤 실행한다. Dockerfile의 각 줄이 어떤 역할을 했는지 설명한다. |
| [3일차](day03/README.md) | 런타임 설정 | 시작은 되지만 제대로 동작하지 않는 컨테이너를 로그, 포트 매핑, 환경 변수를 근거로 고친다. |
| [4일차](day04/README.md) | Docker Compose | Docker Compose로 API와 데이터베이스를 실행하고, API가 DB에 도달하는 방식을 증명한다. |
| [5일차](day05/README.md) | Image 품질과 전달 | Docker Image를 개선하고 크기, 명확성, 안전성, 반복 가능성 중 어떤 점이 좋아졌는지 설명한다. |

## 주차 산출물

- Docker 개념도
- Dockerfile 체크리스트
- Compose 네트워크 다이어그램
- 스틱맨 이미지: 서로 다른 노트북에서 같은 앱을 실행하려는 팀
