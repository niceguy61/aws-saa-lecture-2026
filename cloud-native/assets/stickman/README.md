# Stickman Asset Workspace

This folder is for generated or curated stickman-style images used by the Cloud Native DevOps course.

## Naming

Use stable, searchable filenames:

- `w01-d01-container-process.png`
- `w03-d05-lost-request.png`
- `w04-d04-secret-leak.png`
- `w06-d05-incident-review.png`

## Prompt Source

Keep reusable prompt patterns in [../../design/visual-direction.md](../../design/visual-direction.md) and the root [../../../IMAGE_PROMPTS_STICKMAN.md](../../../IMAGE_PROMPTS_STICKMAN.md).

## Review Checklist

- The image explains a course scenario.
- The image has a clear technical object or conflict.
- The image is not just decoration.
- The image is readable on slides.
- The image does not include secrets, real company names, or unreadable UI text.
