# 6주차 - Observability, 보안, 최종 통합

## 목표

배포 이후의 동작을 관찰하고, 기본 보안을 적용하며, 전체 시스템을 설명할 수 있게 만든다.

## 일별 계획

| 일차 | 주제 | 활동 |
|---|---|---|
| [1일차](day01/README.md) | Observability 기초 | 애플리케이션 로그와 메트릭을 확인하고 어떤 signal이 증상을 가장 잘 설명하는지 말한다. |
| [2일차](day02/README.md) | Kubernetes 보안 기초 | 샘플 workload에서 unsafe default를 찾고 초급 수준에서 더 안전한 대안을 설명한다. |
| [3일차](day03/README.md) | CI/CD와 GitOps 개념 | 강사가 만든 pipeline을 따라 code change부터 deployed workload까지의 흐름을 확인한다. |
| [4일차](day04/README.md) | Capstone 준비 | Architecture, 배포 경로, 실패 사례, 설명 계획을 포함한 최종 시나리오를 준비한다. |
| [5일차](day05/README.md) | Capstone Day | 시스템과 하나의 실패 상황을 설명한다. Architecture, 배포 경로, 증거, 원인, 수정, 예방을 포함한다. |

## 주차 산출물

- Observability 신호 지도
- 보안 기본 체크리스트
- Capstone 평가 루브릭
- 스틱맨 이미지: 로그/메트릭/트레이스를 보며 장애를 회고하는 팀
