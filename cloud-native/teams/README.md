# Cloud Native Course Team Model

The course should be produced by three cooperating groups: Content Production, Instructor Delivery, and Design.

## Content Production Team

Mission: turn the course scope into accurate, teachable, lab-ready materials.

Roles:

- Curriculum Lead: owns week/day sequence, prerequisites, outcomes, and pacing.
- Topic Author: writes theory, decision rules, diagrams, and comparison tables.
- Lab Author: writes hands-on labs, expected output, cleanup, and troubleshooting notes.
- Assessment Author: writes quizzes, scenario questions, and review prompts.
- Technical Reviewer: checks factual accuracy, command safety, and platform assumptions.

Outputs:

- Week README files
- Day README files
- Theory documents
- Lab documents
- Quiz and review documents
- Visual briefs for diagrams and stickman images

## Instructor Team

Mission: make the content teachable in a live classroom.

Roles:

- Lead Instructor: owns delivery flow, timing, and narrative continuity.
- Demo Operator: prepares live demos and fallback recordings or screenshots.
- Lab Coach: supports learners during hands-on work and captures recurring blockers.
- Debrief Facilitator: runs review, discussion, and incident-style retrospectives.

Outputs:

- Instructor notes
- Demo scripts
- Troubleshooting playbooks
- Timing adjustments
- Post-session feedback notes

## Design Partner

Mission: make the course visually consistent, memorable, and useful without turning technical content into decoration.

Roles:

- Visual System Designer: owns typography, color, layout rhythm, callouts, and slide readability.
- Diagram Designer: standardizes Mermaid and redraw candidates.
- Stickman Illustrator: produces scenario images based on reusable prompt patterns.
- Worksheet Designer: formats labs, checklists, and review templates for classroom use.

Outputs:

- Visual direction
- Diagram style guide
- Stickman prompt library
- Slide and worksheet templates

## Weekly Production Loop

1. Curriculum Lead defines scope and outcomes.
2. Topic Author drafts theory and diagrams.
3. Lab Author drafts labs with verification and cleanup.
4. Instructor Team adds delivery notes and failure-mode guidance.
5. Design Partner creates or refines visual assets.
6. Technical Reviewer runs commands and checks links.
7. Main Agent updates status and captures durable lessons.

## Definition Of Ready

A session is ready for classroom use when it has:

- Scenario and learning goals
- Theory with decision rules
- Lab with prerequisites, commands, expected output, verification, and cleanup
- Instructor notes with timing and common mistakes
- Quiz or review prompts
- At least one diagram or visual brief
