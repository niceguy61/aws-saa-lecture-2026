# 1주차 - OT와 컴퓨팅 기초

## 목표

비전공 학생이 Docker, Kubernetes, AWS를 배우기 전에 필요한 최소한의 컴퓨팅 감각과 수업 분위기를 만든다.

## 일별 계획

| 일차 | 주제 | 활동 |
|---|---|---|
| [1일차](day01/README.md) | 과정 OT, 아이스 브레이킹, 개발 환경 준비 | 6주 과정 흐름을 확인하고 Docker Desktop, VS Code, WSL, AI 도구, CLI coding agent 사용 준비를 점검한다. |
| [2일차](day02/README.md) | Cloud Native를 위한 컴퓨팅 기초 | 작은 로컬 웹 애플리케이션을 실행하고, 프로세스, 포트, 요청 경로, 로그를 확인한다. |
| [3일차](day03/README.md) | Linux와 터미널 생존법 | 실패하는 명령어의 원인을 찾고, 에러 메시지를 쉬운 말로 설명한 뒤 올바른 명령어를 작성한다. |
| [4일차](day04/README.md) | 웹 애플리케이션의 모양 | 강사가 만든 재미있는 앱이 설정 누락, 포트 문제, 의존성 장애로 실패하는 모습을 보고 원인을 추론한다. |
| [5일차](day05/README.md) | Cloud와 DevOps 용어 | 코드 변경이 실행 중인 서비스가 되기까지의 배포 이야기를 팀별로 설명한다. 실패 또는 롤백 상황을 하나 포함한다. |

## 주차 산출물

- 초급 용어집
- 로컬 애플리케이션 구조도
- 터미널 생존 워크시트
- 스틱맨 이미지: 팀을 이루어 앱이 서비스가 되는 과정을 이해하는 장면
