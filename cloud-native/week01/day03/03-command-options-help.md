# 3교시 - 명령어 옵션과 help 읽기

## 목표

이 시간의 목표는 명령어를 통째로 외우지 않고 옵션과 도움말을 읽는 법을 익히는 것이다. Cloud Native 도구는 옵션이 많다. 모든 옵션을 외우는 사람보다 필요한 옵션을 찾아 읽는 사람이 더 오래 버틴다.

이 세션의 끝에서 우리는 다음을 할 수 있어야 한다.

- 짧은 옵션과 긴 옵션을 구분한다.
- `--help` 출력에서 사용법과 예시를 찾는다.
- 낯선 명령을 실행하기 전에 안전한 확인 명령을 먼저 찾는다.

## 오늘 한 줄 요약

명령어는 외우는 목록이 아니라, 도움말을 읽으며 조립하는 문장이다.

## 옵션의 두 가지 모양

옵션은 명령의 동작을 바꾸는 스위치다.

| 모양 | 예시 | 특징 |
|---|---|---|
| 짧은 옵션 | `-l`, `-a`, `-n` | 짧지만 의미를 외우기 어렵다 |
| 긴 옵션 | `--all`, `--help`, `--version` | 길지만 의미가 잘 보인다 |

짧은 옵션은 합쳐 쓰기도 한다.

```bash
ls -l -a
```

```bash
ls -la
```

두 명령은 많은 환경에서 비슷하게 동작한다. 하지만 모든 명령이 옵션을 똑같이 해석하지는 않는다. 낯선 명령에서는 `--help`를 먼저 본다.

## 도움말 읽기

명령어의 도움말을 확인한다.

```bash
ls --help
```

환경에 따라 macOS에서는 `ls --help`가 동작하지 않을 수 있다. 그때는 아래 명령을 사용한다.

```bash
man ls
```

`man` 화면에서 나가려면 `q`를 누른다. 이걸 모르면 도움말 화면에 갇힌 것처럼 느껴질 수 있다.

Python 도움말:

```bash
python3 --help
```

또는 Windows:

```bash
py --help
```

Docker 도움말:

```bash
docker --help
```

도움말에서 먼저 볼 부분:

| 볼 것 | 의미 |
|---|---|
| Usage | 명령의 기본 형태 |
| Options | 붙일 수 있는 옵션 |
| Commands | 하위 명령 목록 |
| Examples | 예시가 있으면 가장 먼저 참고 |

## 옵션 선택 미션

현재 위치가 `cloud-native/week01/day03/playground`라고 가정한다.

파일 목록을 자세히 보고 싶다.

```bash
ls -l
```

숨김 파일까지 보고 싶다.

```bash
ls -la
```

로그 파일의 앞부분만 보고 싶다.

```bash
head logs/access.log
```

로그 파일의 마지막 5줄만 보고 싶다.

```bash
tail -n 5 logs/access.log
```

에러 로그에서 `ERROR`가 있는 줄만 보고 싶다.

```bash
grep "ERROR" logs/error.log
```

`grep`은 찾는 단어가 없으면 아무것도 출력하지 않을 수 있다. 출력이 없다는 것은 터미널이 멈춘 것이 아니라, 조건에 맞는 줄을 찾지 못했다는 뜻일 수 있다.

## 종료 코드 맛보기

명령은 성공/실패 상태를 숫자로 남긴다. 보통 `0`은 성공, `0이 아닌 값`은 실패다.

Linux/macOS/WSL:

```bash
grep "ERROR" logs/error.log
echo $?
```

Windows PowerShell:

```powershell
Select-String "ERROR" logs/error.log
$LASTEXITCODE
```

오늘은 종료 코드를 깊게 외우지 않는다. 다만 자동화와 CI/CD에서는 이 성공/실패 숫자가 매우 중요해진다는 것만 기억한다.

## 낯선 명령을 만났을 때

아래 순서로 접근한다.

1. 명령 이름을 본다.
2. `--help` 또는 공식 문서로 사용법을 본다.
3. 읽기 명령인지 변경 명령인지 구분한다.
4. 작은 대상에 먼저 실행한다.
5. 출력과 종료 상태를 기록한다.
