## 랩/미션/데모

오전에는 자기소개와 기대치 공유로 긴장을 풀고, 과정 운영 방식과 6주 학습 흐름을 큰 그림으로 잡는다. 오후에는 실습 환경을 준비하고, CLI 기반 coding agent가 작은 파일을 만들고 명령을 실행할 때 무엇을 확인해야 하는지 살펴본다.

## 설치/확인 체크리스트

- VS Code 또는 본인이 익숙한 코드 편집기
- 터미널: Windows Terminal, PowerShell, macOS Terminal, 또는 Linux shell
- Git
- Docker Desktop
- Windows 학습자: WSL 2 활성화와 Ubuntu 배포판 확인
- 브라우저: Chrome 또는 Edge
- AI 도구 사용 현황: ChatGPT, Claude, Gemini, Copilot, Cursor, CLI coding agent 등

## AI 사용 원칙

- AI는 정답을 대신 제출하는 도구가 아니라 설명을 요청하고, 에러를 해석하고, 실험을 빠르게 만드는 보조 도구로 사용한다.
- AI가 제안한 명령은 실행 전 의미를 확인한다.
- 실습 중 API key, password, token, private key를 AI 도구에 붙여넣지 않는다.
- Coding agent를 사용할 때는 작업 디렉터리와 변경 파일을 확인한다.
