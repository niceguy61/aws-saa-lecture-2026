# 5주차 - AWS 기반 Cloud Native 애플리케이션

## 목표

AWS를 컨테이너 애플리케이션을 배포하고 운영하는 현실적인 클라우드 환경으로 이해한다.

## 일별 계획

| 일차 | 주제 | 활동 |
|---|---|---|
| [1일차](day01/README.md) | AWS OT와 안전 | 위험한 Cloud 사용 습관을 찾아 안전한 수업 규칙으로 바꾼다. |
| [2일차](day02/README.md) | AWS Container Service | 같은 컨테이너 앱을 여러 AWS 배포 선택지에 매핑하고 장단점을 비교한다. |
| [3일차](day03/README.md) | AWS 네트워킹과 외부 노출 | 간단한 애플리케이션의 안전한 외부 노출 경로를 선택하고 private로 남겨야 할 영역을 설명한다. |
| [4일차](day04/README.md) | Managed Data와 Integration | 샘플 애플리케이션이 managed service를 사용할 때 팀이 직접 운영하지 않아도 되는 것과 여전히 책임져야 하는 것을 구분한다. |
| [5일차](day05/README.md) | AWS 설계 스튜디오 | 작은 애플리케이션의 Cloud Native 배포 설계를 만들고 선택 이유를 방어한다. |

## 주차 산출물

- AWS 안전 사용 체크리스트
- AWS Cloud Native 서비스 선택 지도
- 비용 가드레일 워크시트
- 스틱맨 이미지: 관리형 컴퓨팅 옵션을 고르는 팀
