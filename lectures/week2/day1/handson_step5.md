# 👉 Hands-on Lab - Step 5

## 👉 Step 5: Docker 이미지 빌드

**목표**: Dockerfile을 기반으로 이미지 생성

**명령어**:

```bash
docker build -t myapp-image .

```

**예상 출력**:

```

Successfully built <hash>

```

**확인 방법**:

```bash
docker images

```

**문제 해결**:
- 문제: 빌드 실패 → Dockerfile 점검
- 문제: 네트워크 문제 → docker network inspect 확인
