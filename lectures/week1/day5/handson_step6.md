# 👉 Hands-on Lab - Step 6

## 👉 Step 6: 로그 확인

**목표**: 개발 서버 실행 상태 확인

**명령어**:

```bash
docker logs -f <container-id>

```

**예상 출력**:

```

nodemon 로그 출력 (예: [nodemon] starting...)

```

**확인 방법**:

```bash
docker logs <container-id>

```

**문제 해결**:
- 문제: 로그 없음 → 컨테이너 상태 확인: docker inspect <container-id>
