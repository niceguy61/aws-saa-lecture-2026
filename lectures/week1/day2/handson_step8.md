# 👉 Hands-on Lab - Step 8

## 👉 Step 8: 정리 작업

**목표**: 실행 중인 컨테이너 정지 및 삭제

**명령어**:

```bash
docker stop myapp-container && docker rm myapp-container

```

**예상 출력**:

```

Container 정지 및 삭제 완료

```

**확인 방법**:

```bash
docker ps

```

**문제 해결**:
- 문제: 컨테이너 존재하지 않음 -> docker ps -a 확인
