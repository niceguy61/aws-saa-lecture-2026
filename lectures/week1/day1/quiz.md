# 퀴즈 (Quiz)

## ❓ 질문 1

**DevOps의 주요 목적은 무엇인가요?**

A) 개발 및 운영 팀 간의 협업 향상
B) 소프트웨어 개발 속도를 최대화
C) 시스템의 보안 수준을 극대화
D) 서버 비용을 절감하기

<details>
<summary>정답 및 해설 보기</summary>

**답**: A

**설명**: DevOps는 개발(Dev)과 운영(Operations) 팀 간의 협업을 통해 소프트웨어 개발 주기와 배포 효율성을 향상시키는 접근법입니다. 이는 CI/CD, 자동화 도구, 모니터링 시스템 등을 통해 달성됩니다.

</details>

---

## ❓ 질문 2

**배포 중 문제가 발생했을 때, DevOps 관행에 따라 가장 먼저 해야 할 조치는 무엇인가요?**

A) 배포를 즉시 중단하고 원인 분석
B) 사용자에게 알림을 보내고 대기
C) 기존 버전으로 롤백하고 새로운 버전을 재배포
D) 로그를 확인하지 않고 재시도

<details>
<summary>정답 및 해설 보기</summary>

**답**: C

**설명**: DevOps에서 배포 실패 시 즉시 롤백을 통해 서비스 중단을 방지하고, 원인을 분석하여 재배포를 시도하는 것이 중요합니다. 이는 시스템 안정성과 사용자 경험을 보장하는 핵심 원칙입니다.

</details>

---

## ❓ 질문 3

**CI/CD 파이프라인에서 코드 변경을 자동으로 테스트하고 통합하는 명령어는 무엇인가요?**

A) git push
B) docker build
C) terraform apply
D) kubectl apply

<details>
<summary>정답 및 해설 보기</summary>

**답**: A

**설명**: git push는 코드 변경을 원격 저장소에 전송하는 명령어로, CI/CD 파이프라인에서 자동 테스트와 통합을 트리거하는 주요 단계입니다. 다른 명령어는 컨테이너화, 인프라 정의, 클러스터 관리에 해당합니다.

</details>

---

## ❓ 질문 4

**CI와 CD의 주요 차이점은 무엇인가요?**

A) CI는 코드 통합을, CD는 배포 자동화를 의미함
B) CI는 배포 자동화를, CD는 코드 통합을 의미함
C) CI는 사용자 피드백 수집을, CD는 시스템 모니터링을 의미함
D) CI는 데브옵스 도구 사용을, CD는 클라우드 서비스 통합을 의미함

<details>
<summary>정답 및 해설 보기</summary>

**답**: A

**설명**: CI(Continuous Integration)는 개발자들이 자주 코드를 통합하고 자동 테스트를 수행하는 과정을 의미하며, CD(Continuous Delivery/Deployment)는 통합된 코드를 자동으로 배포하거나 준비하는 과정을 의미합니다. 두 단계는 서로 다른 목적과 단계를 가집니다.

</details>

---

## ❓ 질문 5

**DevOps 도구 중 모니터링 및 알림 기능을 제공하는 대표적인 도구는 무엇인가요?**

A) Jenkins
B) Docker
C) Prometheus
D) Terraform

<details>
<summary>정답 및 해설 보기</summary>

**답**: C

**설명**: Prometheus는 메트릭 데이터를 수집하고 시각화하여 시스템 상태를 모니터링하는 데 사용됩니다. Jenkins는 CI/CD 파이프라인을, Docker는 컨테이너화를, Terraform은 인프라 as Code를 위한 도구입니다.

</details>
