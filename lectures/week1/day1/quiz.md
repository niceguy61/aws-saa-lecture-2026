# 퀴즈 (Quiz)

## 질문 1

**DevOps의 주요 목적은 무엇인가요?**

A) 소프트웨어 개발 속도 향상
B) 개발자와 운영팀의 협업 강화
C) 시스템 보안 강화
D) 클라우드 서비스 비용 절감

**답**: B

**설명**: DevOps는 개발자와 운영 팀 간의 협업을 통해 빠른 배포, 지속적인 통합/확장(CI/CD) 및 시스템 안정성을 달성하는 것을 목표로 합니다. 이는 A와 C는 부분적 목표이지만, B가 핵심입니다.

---

## 질문 2

**CI/CD 파이프라인에서 'Continuous Integration'의 주요 역할은 무엇인가요?**

A) 배포 자동화
B) 코드 통합 시 테스트 자동화
C) 서버 모니터링
D) 로그 분석

**답**: B

**설명**: Continuous Integration(CI)는 개발자가 코드를 자주 통합하고, 각 변경 사항에 대해 자동 테스트를 수행하여 버그를 조기에 발견하는 과정입니다. A는 CD(Continuous Deployment)의 역할입니다.

## 질문 3

**아래 명령어 중 Docker 컨테이너를 실행하는 것은 무엇인가요?**

A) docker build
B) docker run
C) docker commit
D) docker push

**답**: B

**설명**: docker run은 이미지에서 컨테이너를 생성하고 실행하는 명령어입니다. docker build는 이미지 생성, commit은 컨테이너를 이미지로 저장, push는 이미지를 registry에 업로드하는 역할입니다.

## 질문 4

**아래 중 DevOps와 Agile의 주요 차이점은 무엇인가요?**

A) Agile은 개발 중심, DevOps는 운영 중심
B) Agile은 단일 팀 중심, DevOps는 다학제 협업 중심
C) Agile은 수동 테스트, DevOps는 자동 테스트
D) Agile은 기능 중심, DevOps는 성능 중심

**답**: B

**설명**: Agile은 개발 단계에 중점을 두고, DevOps는 개발과 운영 팀의 협업을 강조합니다. B는 두 접근법의 핵심 차이를 정확히 반영합니다. 나머지는 부분적 특징일 뿐입니다.

## 질문 5

**AWS에서 CI/CD를 구현할 때 사용하는 서비스는 무엇인가요?**

A) EC2
B) CodePipeline
C) S3
D) Lambda

**답**: B

**설명**: AWS CodePipeline은 CI/CD 파이프라인을 자동화하는 서비스로, 코드 변경 사항을 받아들여 테스트, 빌드, 배포까지 자동화합니다. EC2는 인스턴스 관리, S3는 저장소, Lambda는 함수 실행에 사용됩니다.
