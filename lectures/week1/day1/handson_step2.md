# 👉 Hands-on Lab - Step 2

## 👉 Step 2: Dockerfile 작성

**목표**: Nginx 기반 컨테이너 이미지를 생성합니다.

**명령어**:

```bash
echo 'FROM nginx:latest' > Dockerfile

```

**예상 출력**:

```

Dockerfile 파일 생성됨

```

**확인 방법**:

```bash
cat Dockerfile

```

**문제 해결**:
- 문제: 파일 생성 실패 → sudo nano Dockerfile 사용
- 문제: 파일 내용 오류 → echo 명령어 재실행
