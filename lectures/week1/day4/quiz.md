# 퀴즈 (Quiz)

## 질문 1

**Docker 명령어에서 `-w /app` 옵션의 주요 기능은 무엇인가요?**

A) 컨테이너의 포트를 호스트 포트로 매핑  
B) 커맨드가 실행될 작업 디렉터리 설정  
C) 컨테이너 내부에서 파일 시스템을 암호화  
D) 호스트 시스템의 파일 시스템을 컨테이너에 복사  

<details>
<summary>정답 및 해설 보기</summary>

**답**: B  

**설명**: `-w /app`는 **작업 디렉터리(working directory)**를 설정하는 옵션입니다. 이는 Dockerfile에서 `WORKDIR /app`처럼 사용되며, 명령어가 실행될 때 기준이 되는 경로를 정합니다. 예를 들어, `sh -c "npm install && npm run dev"` 명령어는 `/app` 디렉터리에서 실행되며, 이는 프로젝트 파일이 저장된 경로를 의미합니다.  
- **WORKDIR**: Dockerfile에서 작업 디렉터리를 설정하는 명령어입니다.  
- **작업 디렉터리**: 명령어가 실행될 때 기준이 되는 경로입니다.  

</details>

## 질문 2

**Docker Compose에서 `--mount type=bind,src=.,target=/app` 구문의 주된 목적은 무엇인가요?**

A) 호스트의 특정 포트를 컨테이너 포트로 매핑  
B) 호스트 디렉터리와 컨테이너 디렉터리 간의 바인드 마운트 설정  
C) 컨테이너 내부의 파일 시스템을 암호화  
D) 컨테이너 이미지의 버전을 관리  

<details>
<summary>정답 및 해설 보기</summary>

**답**: B  

**설명**: `--mount`는 **바인드 마운트(bind mount)**를 설정하는 옵션입니다. 바인드 마운트는 호스트 컴퓨터의 파일과 컨테이너의 파일을 실시간으로 동기화하는 기능입니다. 예를 들어, 현재 디렉터리(`src=.`)를 컨테이너의 `/app` 디렉터리로 연결하면, 호스트에서 파일을 변경하면 컨테이너도 즉시 반영됩니다.  
- **바인드 마운트**: 호스트와 컨테이너 간의 파일 시스템을 실시간으로 공유하는 기능입니다.  
- **동기화**: 호스트의 파일 변경이 컨테이너에 자동으로 반영됩니다.  

</details>

## 질문 3

**Docker bind mount에서 `:z` 옵션과 `:Z` 옵션의 주요 차이는 무엇인가요?**

A) `:z`는 SELinux 권한을 무시하고 `:Z`는 권한을 적용함  
B) `:z`는 여러 컨테이너가 공유할 수 있도록 설정하고 `:Z`는 단일 컨테이너만 사용 가능함  
C) `:z`는 읽기 전용으로 설정하고 `:Z`는 읽기-쓰기로 설정함  
D) `:z`는 호스트 파일 시스템을 복사하고 `:Z`는 네트워크 파일 시스템을 사용함  

<details>
<summary>정답 및 해설 보기</summary>

**답**: B  

**설명**:  
- **`:z` 옵션**: SELinux 보안 정책을 유지하면서, 여러 컨테이너가 동일한 디렉터리를 공유할 수 있도록 설정합니다. 예를 들어, 여러 개발자가 같은 코드를 함께 작업할 때 사용됩니다.  
- **`:Z` 옵션**: SELinux 보안 정책을 무시하고, 단일 컨테이너만 사용할 수 있도록 설정합니다. 이는 보안 위험을 줄이기 위해 사용됩니다.  
- **SELinux**: 컨테이너가 파일을 접근할 수 있는 권한을 제어하는 시스템 보안 기능입니다.  

</details>

## 질문 4

**Docker Compose의 `watch` 모드에서 `sync+restart` 동작이 필요한 시나리오는 무엇인가요?**

A) `package.json` 변경 시 의존성 설치  
B) `nginx.conf` 파일 변경 시 서버 재시작  
C) `node_modules` 디렉터리 변경 시 파일 복사  
D) 호스트 디렉터리 변경 시 컨테이너 로그 확인  

<details>
<summary>정답 및 해설 보기</summary>

**답**: A  

**설명**: `sync+restart` 동작은 파일이 변경되면 컨테이너를 재빌드하고 재시작하는 방식입니다. 예를 들어, `package.json` 파일을 수정하면 `npm install`이 자동으로 실행되고, 애플리케이션이 재시작됩니다.  
- **sync+restart**: 파일 변경 시 컨테이너를 재빌드하고 재시작하는 동작입니다.  
- **의존성 설치**: `package.json` 변경 시 의존성 패키지가 자동으로 설치됩니다.  

</details>

## 질문 5

**Docker에서 비밀 정보를 파일과 환경 변수로 동시에 마운트하는 방법은 무엇인가요?**

A) `--mount type=secret`과 `env` 옵션 함께 사용  
B) `--mount type=bind`와 `target` 옵션 함께 사용  
C) `--mount type=ssh`와 `secret` 옵션 함께 사용  
D) `--mount type=volume`과 `env` 옵션 함께 사용  

<details>
<summary>정답 및 해설 보기</summary>

**답**: A  

**설명**:  
- **`--mount type=secret`**: 비밀 정보를 파일로 마운트합니다. 예를 들어, AWS 자격 증명을 파일로 저장할 수 있습니다.  
- **`env` 옵션**: 동일한 비밀 정보를 환경 변수로 전달합니다. 이는 애플리케이션이 파일과 환경 변수 모두에서 정보를 읽을 수 있도록 합니다.  
- **Docker secrets**: 민감 정보를 암호화하여 안전하게 전달하는 기능입니다.  

</details>
