# 👉 Hands-on Lab - Step 3

## 👉 Step 3: package.json 파일 생성

**목표**: npm 의존성 및 스크립트 정의

**명령어**:

```bash
echo '{"name":"docker-app","scripts":{"start":"node index.js","dev":"nodemon index.js"},"dependencies":{"express":"4.18.2","nodemon":"3.0.2"}}' > package.json

```

**예상 출력**:

```

package.json 파일 생성됨

```

**확인 방법**:

```bash
cat package.json

```

**문제 해결**:
- 문제: JSON 구문 오류
  해결: echo 명령어에서 따옴표 검토
